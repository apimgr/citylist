API Endpoints

GET /api/v1/cities

List all cities with pagination support.

Query Parameters

Name Type Default Description
page integer 1 Page number
limit integer 50 Results per page (max: 1000)
GET /api/v1/cities/search

Search cities by name with case-insensitive substring matching.

Query Parameters

Name Type Default Description
q required string - Search query (min 2 characters)
limit integer 20 Max results (max: 100)
GET /api/v1/cities/{id}

Get a specific city by its unique identifier.

Path Parameters

Name Type Description
id required integer City ID
GET /api/v1/cities/country/{code}

Get all cities in a country by ISO 3166-1 alpha-2 code.

Path Parameters

Name Type Description
code required string Country code (e.g., US, GB, JP)

Query Parameters

Name Type Default Description
limit integer 50 Max results (max: 1000)
GET /api/v1/cities/coordinates

Find the nearest city to given geographic coordinates.

Query Parameters

Name Type Description
lat required number Latitude (-90 to 90)
lon required number Longitude (-180 to 180)
GET /api/v1/cities/nearby

Find cities within a radius of given coordinates using Haversine distance.

Query Parameters

Name Type Default Description
lat required number - Latitude (-90 to 90)
lon required number - Longitude (-180 to 180)
radius number 50 Search radius in km
limit integer 10 Max results (max: 100)
GET /api/v1/stats

Get API statistics including city and country counts.

Also available as /api/v1/stats.txt for plain text format.

GET /api/data

Get the raw city database as JSON (large file).
